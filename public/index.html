01

Enable PowerShell logging

Run the included setup script from an administrator PowerShell window. It enables Script Block Logging for Windows PowerShell and PowerShell 7, and saves the previous policy values.

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Enable-Logging.ps1

New PowerShell sessions pick up the change. Scripts and command arguments may contain secrets; Windows retains these logs independently of Observe.

02

Configure Microsoft Sysmon

Download Sysmon from Microsoft, review its license, and install it with the included event configuration. The helper verifies the Microsoft signature before running it.

.\scripts\Install-Sysmon.ps1 -SysmonPath C:\Tools\Sysmon64.exe

Requires an administrator PowerShell window. If Sysmon is already managed by your organization, ask the administrator to check coverage instead of replacing its configuration.

03

Check permissions & coverage

Refresh Device readiness. If access is denied, launch Observe from an administrator terminal for a local test. Production deployments should give a dedicated collector the minimum event-log access it needs.

Sysmon should include process creation, network connections, DNS, file creation, registry changes, and process tampering. A readable channel alone does not confirm that every event type is enabled.

04

Choose how to use Astra

Self-hosted: use your OpenAI API key in Advanced settings. Your key stays in the local server’s memory.

Managed: enter your service URL and access token. The service pays OpenAI and can manage your request allowance.

The MVP includes the managed gateway. Public hosting, checkout, and account provisioning are deployment work.
